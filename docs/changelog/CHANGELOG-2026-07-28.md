## 技术细节

### 工具栏固定原理

```
问题：backdrop-filter 创建新的包含块
      ↓
position: fixed 不再相对于视口定位
      ↓
解决：将工具栏移到 body 下
      ↓
脱离 backdrop-filter 的影响
      ↓
position: fixed 正常工作
```

### 单个视频爬取流程

```
用户输入 BV 号/AV 号/链接
      ↓
解析并转换为 BV 号
      ↓
检查数据库是否已存在
      ↓
是 → 弹出确认框 → 用户确认 → 更新统计
否 → 获取视频完整信息 → 创建记录
      ↓
创建/更新 UP 主（仅基本信息）
      ↓
创建视频历史记录
      ↓
返回成功提示
```

### 日历选择器技术细节

```
布局结构（从上到下）：
├─ 年份选择行：[‹] [2026] [›]
├─ 月份选择行：[‹] [7月] [›]
├─ 星期表头：日 一 二 三 四 五 六
└─ 日期网格：6行×7列完整矩阵

拖拽选择流程：
鼠标按下 → 记录起始日期
    ↓
鼠标移动 → 实时预览范围
    ↓
移动到边缘 → 自动切换月份
    ↓
鼠标松开 → 确认选择并更新图表

智能日期解析：
时间标签格式：MM/DD HH:MM（无年份）
    ↓
第一个数据点：使用系统年份
    ↓
后续数据点：根据前一个日期推断年份
    ↓
月份跳跃 > 1：跨年（年份+1）
月份倒退 > 1：前一年（年份-1）
```
